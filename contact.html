お問い合わせ

公開初期は、誤情報・リンク切れ・表示不具合・権利関係などのご連絡をGitHub Issuesで受け付けています。

個人情報・秘密情報は投稿しないでください。

GitHub Issuesの投稿内容は公開される場合があります。氏名、住所、電話番号、メールアドレス、ログイン情報、ポイントサイトの会員情報などは記載しないでください。

GitHub Issuesで連絡する

ご連絡時にあると助かる情報

  • 対象のゲーム名・ページ名
  • 誤っている、または表示されない内容
  • 確認したポイントサイト名
  • 可能であれば確認日時

専用のお問い合わせフォーム等を用意した場合は、本ページの窓口を更新します。
