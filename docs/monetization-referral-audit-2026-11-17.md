# POIGAME LAB 紹介報酬導線監査（2026-11-17）

## 調査対象と範囲
- `main` の `site-referrals.js`, `index.html`, `game.html`, `about.html`, `data/verified_offer_urls.json`（更新前のソースを確認）
- 実際の紹介登録・紹介報酬の発生はポイントサイトの各会員アカウントで確認する必要がある。この監査は成果計測を実証したものではない
- このPRは導線の説明と静的テストのみ。紹介URL・コード、案件URL、CSV、データ取得、更新処理、ランキング、AdSense設定は変更しない

## 確認したこと
1. `site-referrals.js` は11サイト分の紹介情報を定義している。10サイトには紹介URLがあり、MIKOSHI は紹介コードのみでURLが空欄。設定された値が実際に本人のアカウントに紐づいているか、現在有効かは未検証
2. `index.html` の「最高還元サイトへ」は `bestOffer.url` を使用する。［PR］の新規会員登録は `referral.url` を使用する
3. `game.html` の「案件を見る」は `offer.url`、［PR］の紹介登録は `referral.url` であり、同じではない。例として `data/verified_offer_urls.json` にはワラウの個別案件 `pointEntrance.php?point_id=...` が保存されている
4. ［PR］経由での新規登録が紹介特典の対象になり得る。ただし、公開の案件情報ページへ直接移動しただけでは**このサイトの紹介コードによる新規登録を意味しない**
5. ワラウの紹介URL末尾と、登録画面に表示される紹介コードは異なる場合があり、**公式ヘルプが正常な判定を明記**。一致させる目的での修正は不要
6. ワラウの友達紹介は、新規登録した人が所定期間内に広告利用などの条件を満たす必要がある。モッピーには友達紹介と対象広告のダウン報酬がある。適用条件・対象広告・期限は公式表示で都度確認する

## このPRでの改善
- トップページ：比較用の案件リンクと［PR］の紹介登録リンクが異なることを、ゲーム一覧の前に説明
- ゲーム詳細：比較表の前と「見方」の説明に区別を記載
- 運営情報ページ：紹介特典を保証せず、読者の登録導線と案件条件確認の順番を説明
- 静的回帰テスト：導線説明、［PR］明示、案件リンクと紹介リンクのソース分離を検査

## 本番反映後に必要なオーナー確認
- 各ポイントサイトにログインし、`site-referrals.js` のURLとコードが**自分の紹介専用情報**か照合する（特にMIKOSHIのコードだけの状態）
- 可能なら各公式紹介ページでアカウントの紹介制度利用条件を満たしているか確認する（例：ワラウは交換・電話認証）
- 「紹介人数」「紹介成果」「特典付与」「ダウン報酬」など管理画面の実績で追跡する。表示されたボタンをクリックできることと報酬発生は同義ではない
- サイト・案件ページの拡散禁止、SNS・ブログ紹介規約は個別のポイントサイト/案件ごとに確認する。ワラウ公式ヘルプは広告によって拡散禁止の場合があると注意している
- 案件単位のASP提携・特別紹介案件への応募は、既存の友達紹介プログラムとは別途契約確認が必要。契約無しで案件URLに報酬識別子を付与しない
