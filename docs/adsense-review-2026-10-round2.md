### progress.htmlの5ページを検索対象から外すか（2026-10-17 検討）

| | 内容 |
| --- | --- |
| 確認できた事実 | 本番の`progress.html`は`index,follow`。sitemap.xmlには未掲載。内部リンクは`guides.html`、`site-guides.js`（5ゲームのカード）、`site-header.js`（Townshipの導線）のみ。5ページのうち、きのこ伝説・メメントモリ・ワーキングヒーロー・ホワイトアウトの4つは、同じ実例パネル（同じJSON）が各攻略ページにもある。**Townshipは攻略ページ（township-lv70.html）に実例パネルがなく、`progress.html?game=Township`だけが実例の掲載場所** |
| 確認できなかったこと | 5ページの検索流入・表示回数・インデックス状況。Search Console（Windsor.ai経由）は、無料プランのアカウント数上限（許可1／接続6）で数値が読み取れない。`site:`検索でも本番の該当ページは確認できなかったが、検索エンジンのインデックスの有無を示す証拠にはならない |
| noindexのメリット | 4ページは攻略ページと内容が重複するため、重複・薄いページの印象を避けられる。クロール先が攻略ページに集中する |
| noindexのデメリット | 既にインデックスされて流入があれば、その流入を失う。Townshipの実例は、ここだけが掲載場所なので、検索から消えると独自の実例が検索対象でなくなる。数値を確認せずに外すと、元に戻した後の再インデックスにも時間がかかる |
| 採用した方針 | 5ページは現状維持（`index,follow`）。記録のない状態のページは表示せず`guides.html`へ移動（薄いページを作らない）。JavaScriptで後から`noindex`を付ける方式は、検索エンジンが反映するとは限らないため採用しない |
| 次の判断（運営者） | Search Consoleで、5ページ（`/progress.html?game=...`）の表示回数・クリック・「インデックス登録されていない理由」を確認。流入が無く、攻略ページと重複する4ページだけを外す場合は、ページを分けるか、攻略ページへのリンクに置き換える。Townshipは攻略ページに実例パネルを追加してから整理する |

## A-4 公式ポリシーとの照合（2026-10-16に確認したページ）

参照：Google AdSense プログラム ポリシー（広告枠の価値）、Google 検索セントラル スパムに関するポリシー、役に立つコンテンツの作成。

**確認できた事実**
- AdSenseのポリシーは、広告を表示できない画面として「パブリッシャーのコンテンツが含まれていない、または有用性の低いコンテンツを含んでいる」「作成中である」画面を挙げている。
- 他者のコンテンツの転載は、コメント・キュレーション・価値の追加がない場合に対象。
- 「パブリッシャーのコンテンツよりも広告や有料の宣伝用資料の方が多い」画面も対象。
- 検索のスパムポリシーは、独自性のない大量ページ（scaled content abuse）、商品説明をそのまま使うだけのアフィリエイト（thin affiliation）、特定クエリ向けに作ったページへの誘導（doorway）を挙げる。良いアフィリエイトサイトは「意味のあるコンテンツや機能で価値を加える」としている。
- 役に立つコンテンツの作成ガイドは、独自の情報、制作者の明示、作成方法の開示（自動化・AIの利用）、架空の著者名の禁止を挙げる。
