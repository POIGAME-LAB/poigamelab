# 日次攻略制作：「178候補→完成1本」の原因と修正（2026-11-19の再評価）

対象：PR #348で入れた日次攻略制作システム。参考にした実行：PR #351（2026-11-19、候補178件、完成1本）。
この文書は運営者向けです。プログラムの知識がなくても読めるように書いています。

**結論を先に。** 1本しか作れなかったのは「候補が少なかったから」ではなく、**調べる仕組みが狭かった**からです。仕組みは直しました。ただし、直しても**毎日5本が保証されるわけではありません**。次の壁は「実際にそのゲームを遊んだ人の、独立した記録が2人以上あるか」で、これは仕組みでは作れない情報です。捏造して水増しはしません。

## 1. なぜ178件が1本になったか

| 段階 | 件数 | 何が起きたか |
| --- | ---: | --- |
| 候補 | 178 | スキャンで見つかったゲーム名 |
| 実際に見た | 約15 | 報酬の大きい順に上から見て、そこで止まった |
| 条件を確認できた | 数件 | 見ていたのはワラウの案件ページだけ |
| 完成 | 1 | 大家さんになろう！ |

見た約15件のうち**9件はワラウの「SKYFLAG」案件**で、ログインなしでは中身が表示されません（読めないページに調査枠を使っていた）。同じゲームのCOINCOME・アメフリ・モッピーのページは見ていませんでした。

## 2. 原因：仕組みの問題と、情報不足を分けて

### 仕組みの問題（直せるもの。今回直した）

1. **証拠を集める部分がワラウと「StepUp（段階達成型）」しか知らなかった。** アメフリ・COINCOME・モッピーは読めず、「レベル○○到達」のような**1つだけの条件の案件（約90件）**は表現できなかった。
2. **「攻略がある」と「比較データ・調査メモがある」を同じに扱っていた。** データだけのゲームが「もう攻略済み」として候補から落ちていた。
3. **調べる順番が報酬額だけだった。** 「読めるサイトがあるか」「複数サイトで確認できるか」を見ていなかった。
4. **アメフリの案件が候補にほとんど入らなかった**（11/19は256件中1件）。

### 情報不足（仕組みでは直せないもの）

1. モッピーのStepUpは、各段階の中身が案件ページに出ない（公開されない）。
2. ワラウSKYFLAGはログインなしで見られない。
3. **新しく掲載された案件ほど、遊んだ人の公開記録がまだない。**
